# Legacy business drawing source

`legacy-business-drawing.zip` preserves the drawing and DWG modules removed from the business-management project on 2026-10-14, together with their dedicated tests, browser check, and prior registration files.

The archive contains source code, not the user's browser-saved drawings. Each archived file has a SHA-256 entry in `backup-manifest.json`, verified before removal from the business project.

The active standalone CAD source is in `../src/`. Use `../간이캐드 실행.lnk` or `../간이캐드.html` to run it. Archived files are not loaded or built by either application.
