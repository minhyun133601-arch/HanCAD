# Parity checklist

These checks track reference behavior and unresolved compatibility. A registered
command is not an implemented command.

- [ ] Complete deferred original Phase 00 native Korean shell startup, minimum 1280x720 and size/position restoration; user-directed Phase 01 advancement does not verify those items.
- [ ] Audit all user-visible diagnostics against typed ko-KR/en-US catalogs; bilingual progress content alone does not complete i18n.
- [ ] Compare localized importer line/limit errors, warnings after language switch/recovery and current-language cancellation against the installed Korean reference; preserve arbitrary external diagnostics verbatim.
- [ ] Verify renderer startup failure retains the shell and command input in both locales; injected browser context failures do not prove native WebView2 behavior.
- [ ] Phase 02 colors: compare the ACI table in the Select Color dialog (8, 9, 10-19, 109, 249 and 250-255) and how AutoCAD adjusts dark grays close to the model background; HanCAD only inverts color 7/top-level ByBlock.
- [ ] Phase 02 lineweights: measure model-space pixel widths with LWDISPLAY on for 0.13/0.25/0.30/0.50/0.70/1.00/2.11 mm at the default display scale (HanCAD: 1/1/2/2/3/4/9 px).
- [ ] Phase 02 linetypes: compare DASHED/CENTER/HIDDEN/PHANTOM dash placement on lines, arcs, circles (start angle) and polylines with PLINEGEN 0/1, short objects drawn continuous, DOT end dashes and LTSCALE/CELTSCALE/MSLTSCALE with an annotation scale.
- [ ] Phase 02 GPU display: compare one-pixel stroke antialiasing, lineweight caps/joins, dash dots and light/dark ACI 7 at Windows display scales 100%, 125%, 150% and 200%; browser/Canvas2D golden tolerance is not installed-AutoCAD equivalence.
- [ ] Phase 02 geometry: compare adaptive bulged/tapered polylines (including shallow arcs at survey coordinates), FILLMODE outlines, rational NURBS/ellipses, oblique XY projections and view-clipped XLINE/RAY with the reference; native geometry support does not imply native TEXT/MTEXT/block/dimension producer support.
- [ ] Phase 02 precision: compare subpixel pan and small arcs/widths at (200000000, 450000000) and view scales 65536/262144 in installed AutoCAD; renderer contracts prove identical binary-line frames and bounded arc rounding at those scales, not reference-product parity.
- [ ] Phase 02 points: compare every PDMODE base plus circle/square combination and PDSIZE positive/zero/negative behavior across zoom and REGEN; HanCAD captures percentage size from the last regenerated view height.
- [ ] Phase 02 style creation/recovery: compare CECOLOR/CELTYPE/CELWEIGHT/CELTSCALE/CETRANSPARENCY/PLINEGEN on new LINE/PLINE/CIRCLE/TEXT/dimensions and imported ByLayer/ByBlock entities; implement CECOLOR HSL/color-book resolution and complex linetype glyphs with their owning producers.
- [ ] Phase 02 text: compare Arial/Malgun Gothic punctuation, baseline/cap height, centered dimension labels, multiline spacing and rotations against the installed fonts; the legacy dimension middle-to-baseline offset is currently 0.35 em and text picking uses estimated bounds.
- [ ] Phase 02 draw order: compare opaque/translucent strokes, fills, text and selected objects across chunk boundaries, including hidden-layer changes; real-browser probes cover representative overlaps, not every transparency ordering case.
- [ ] Phase 02 navigation: compare Korean prompts/clickable keywords, All versus limits, Center height/scale, Dynamic move/resize/Enter/Escape, Object selection completion, ten Previous views, bare/X/XP scale contexts, realtime zoom and PAN/-PAN; XP UI requires the later floating-layout-viewport producer.
- [ ] Phase 02 regeneration/transitions: compare REGEN/REGENALL/REDRAW/REDRAWALL across future viewports, VTENABLE bits, VTDURATION, VTFPS fallback and navigation UNDO; current All variants address the sole active model viewport.
- [ ] Phase 02 fit margin: measure AutoCAD ZOOM Extents and double-middle viewport padding; HanCAD currently uses a shared 0.95 fill factor, with ZOOM All relative PDSIZE captured from the final view.
- [ ] Phase 02 aids: compare CURSORSIZE/PICKBOX at high DPI, UCSICON origin/lower-left fallback and GRIDUNIT/GRIDMAJOR/GRIDDISPLAY/GRIDSTYLE adaptive thresholds; dynamic UCS bit 8, selectable/3D UCS icons, UCSICON Properties/All and non-model grid producers remain later work.
- [ ] Phase 02 background: verify OPTIONS model-background colors and persistence against the Korean reference; the current dialog is a documented subset, not the complete AutoCAD Options dialog.
- [ ] Phase 03 catalog: compare the Korean display names and one-line help of all catalog commands (`pnpm docs:commands` table) with the Korean help/ribbon tooltips, especially names not in GLOSSARY.md (e.g. 기준점을 사용하여 복사, 일반 DWG로 내보내기, 회전 for both ROTATE and REVOLVE).
- [ ] Phase 03 messages: compare the transparent-command error (`** 해당 명령은 투명하게 호출할 수 없습니다 **`), the resume line (`LINE 명령 재개 중.`) and the external-command behavior with the Korean reference; check whether Space accepts at layer/block name prompts and inserts a space in string SETVAR values.
- [ ] Phase 03 flags: verify which commands accept the ' prefix (HanCAD list in `catalog/flags.ts`), which open modal dialogs and which use the PICKFIRST set.
- [ ] Phase 03 command window: measure the floating bar's default width/position/transparency and how long temporary prompt lines stay before fading (HanCAD: 930 px, 25%, 5 s); compare the close-confirmation wording, the customize (wrench) and recent-command menus, the right-click menu items and their order, F2 floating/docked behavior, Ctrl+F2, TEXTSCR/GRAPHSCR and the docked drawing-area resize.
- [ ] Phase 03 AutoComplete: compare which entries appear for OSM, LI, LINE, ISO and CIRLCE, and in what order (exact/alias first, prefix, mid-string, AutoCorrect; frequency versus alphabetical); whether Enter/Space runs the top suggestion before the list opens; whether the completion is shown inline and from which keystroke; Up/Down/Tab/Shift+Tab and Backspace behavior; how the separate system-variable list looks and how Tab opens it; icons and placement of the list.
- [ ] Phase 03 AutoCorrect: compare when a mistype counts toward "n번 잘못 입력한 후에 수정 사항 저장" (default 3 in HanCAD), the fuzzy suggestions for misspellings without a learned entry, and the AutoCorrectUserDB.pgp format.
- [ ] Phase 03 INPUTSEARCHOPTIONS: compare the dialog layout, the sort-order caption, the defaults (including "명령 및 시스템 변수 분리" off), the delay range, and the -INPUTSEARCHOPTIONS top-level prompt, keyword letters and yes/no prompt format.
- [ ] Phase 03 transparent commands: compare the echo of an apostrophe entry, the >> prompt prefix, the name shown before the prompt while 'ZOOM runs, the resume line `LINE 명령 재개 중.`, whether Esc during 'ZOOM also cancels LINE, the message for a nested or non-transparent entry, and 'DIST/'SETVAR/'variable behavior inside LINE, MOVE and an UNDO prompt.
- [ ] Phase 03 LINE prompts: confirm `[명령 취소(U)]` after the first and second points and `[닫기(C)/명령 취소(U)]` from the third, and the message when C is typed too early.
- [ ] Phase 03 PGP: compare REINIT dialog wording and defaults, whether REINIT reports PGP errors, RE-INIT reset behavior, whether AutoCAD reads a UTF-8 acad.pgp with Korean comments written by HanCAD, and the ALIASEDIT (Express Tools) dialog layout and Korean wording.
- [ ] Phase 03 macros: compare the history after ribbon clicks (`명령: _LINE`, `*취소*` when a command was running), `^C^C` with a preselection, the automatic trailing space, `\` pauses for points and selections, `*^C^C` repetition and how it ends, `^P`/MENUECHO echo and `^Q`, and the transparent "Zoom Extents" ribbon button inside LINE.
- [ ] Phase 03 DIESEL: compare number formatting of arithmetic results, rtos/angtos for every mode, edtime phrases, space handling around arguments, `$(if,0,x)`, getenv sources, the output length limit and MODEMACRO placement and refresh.
- [ ] Phase 03 aliases: compare the 172 extended aliases (alternative, legacy and discontinued-command sections of an installed acad.pgp) with the current release's acad.pgp; confirm GCON=GEOMCONSTRAINT and ED=TEXTEDIT.
- [ ] Choose and document one installed AutoCAD reference release and template.
- [ ] Verify Korean prompts against the reference release.
- [ ] Verify the original shortcut table against the reference/user PGP profile.
- [ ] Verify default variables by drawing, profile and session scope.
- [ ] Compare the native acadiso default reference graph: styles, exact numeric fields/fonts, layout/block/viewport ownership, paper setup and 25 scale-list entries/order.
- [ ] Verify all documented DXF entity/object variants and contexts against real files; SCALE currently has common group metadata only, and most record types remain opaque rather than editable.
- [ ] Verify mapped edits retain duplicate/unknown groups, subclass/application boundaries, dictionary entries, XDATA, reactors, extension dictionaries and per-vertex data through future DXF I/O.
- [ ] Compare OCS/arbitrary-axis coordinates, ARC degrees, ellipse parameters, bulged/width polylines and affine transforms with the reference; wire pure native geometry into persistent edit commands.
- [ ] Compare numerical NURBS/fit spline closest points, length, area and conservative bounds; verify natural omitted-tangent conditions/nonzero fit tolerance, matching periodic tangents and the unsupported arbitrary periodic tangent case.
- [ ] Compare live providers with installed AutoCAD: DATE/CDATE (HanCAD discards milliseconds), TDCREATE/TDUPDATE/TDINDWG/TDUSRTIMER after NEW/save/reopen, UCSNAME `""` in World, CLAYOUT `name*handle` after tab clicks and SETVAR, EXTMIN/EXTMAX (HanCAD reports live geometry bounds; empty = ±1E+20), VIEWCTR/VIEWSIZE/SCREENSIZE, LOCALE KOR/ENU and closed-palette state 0. Identity/path/codepage values (LOGINNAME, PLATFORM, SYSCODEPAGE, DWGCODEPAGE, ACADVER, PRODUCT, user paths) stay explicitly unavailable in browser mode and need a native provider.
- [ ] Verify the 28 audited documented ranges (e.g. CBARTRANSPARENCY 10-90, CLIPROMPTLINES 0-50, TEXTQLTY 0-100) reject out-of-range input with the same Korean message; SELECTIONEFFECTCOLOR accepts 0 (documented initial) plus 1-255. Confirm normalized angles (GFANG, LOFTANG1/2) and conditional limits (FACETERSMOOTHLEV, MAXACTVP) that HanCAD does not reject.
- [ ] Check whether switching layout tabs is recorded in the undo journal (HanCAD: tab clicks are not, SETVAR CLAYOUT is).
- [ ] Verify Korean direct-sysvar prompts, OSMODE 4133/invalid 99999, SETVAR LUPREC 2, read-only values and all shared-profile/per-document scopes against installed AutoCAD.
- [ ] Compare UNDO count/marks/groups/Control and live UNDOCTL. Wheel zoom, middle-button pan, double-middle and ZOOM E are recorded navigation steps merged by Combine; check U/REDO restore the identical view. Auto groups a whole `runMacro` menu macro; verify against a real multi-command menu item once Phase 03 macros exist.
- [ ] Layer category combination (UNDO Control Layer) awaits the Phase 08 Layer Properties Manager; the journal already merges consecutive `layer` changes.
- [ ] Compare implemented REDO's immediate-after-U/UNDO window and last undo batch against the installed reference; compare MREDO count/All/Last and OOPS after intervening edits and document reactivation.
- [ ] Verify NEW/OPEN/tab switching preserve independent graphs/history/blobs and shared profiles; provisional commands cancel without leaking into another document.
- [ ] Verify full .hcd and active recovery preserve opaque records/reference graphs/blobs; test delayed old-document cache writes and failures, and distinguish clean reload history from retained tab history.
