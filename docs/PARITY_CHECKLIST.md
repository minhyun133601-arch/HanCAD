# Parity checklist

These checks track reference behavior and unresolved compatibility. A registered
command is not an implemented command.

- [ ] Complete deferred original Phase 00 native Korean shell startup, minimum 1280x720 and size/position restoration; user-directed Phase 01 advancement does not verify those items.
- [ ] Audit all user-visible diagnostics against typed ko-KR/en-US catalogs; bilingual progress content alone does not complete i18n.
- [ ] Compare localized importer line/limit errors, warnings after language switch/recovery and current-language cancellation against the installed Korean reference; preserve arbitrary external diagnostics verbatim.
- [ ] Verify renderer startup failure retains the shell and command input in both locales; injected browser context failures do not prove native WebView2 behavior.
- [ ] Phase 02 colors: compare the ACI table in the Select Color dialog (8, 9, 10-19, 109, 249 and 250-255) and how AutoCAD adjusts dark grays close to the model background; HanCAD only inverts color 7/top-level ByBlock.
- [ ] Phase 02 lineweights: measure model-space pixel widths with LWDISPLAY on for 0.13/0.25/0.30/0.50/0.70/1.00/2.11 mm at the default display scale (HanCAD: 1/1/2/2/3/4/9 px).
- [ ] Phase 02 linetypes: compare DASHED/CENTER/HIDDEN/PHANTOM dash placement on lines, arcs, circles (start angle) and polylines with PLINEGEN 0/1, short objects drawn continuous, DOT end dashes and LTSCALE/CELTSCALE/MSLTSCALE with an annotation scale.
- [ ] Choose and document one installed AutoCAD reference release and template.
- [ ] Verify Korean prompts against the reference release.
- [ ] Verify the original shortcut table against the reference/user PGP profile.
- [ ] Verify default variables by drawing, profile and session scope.
- [ ] Compare the native acadiso default reference graph: styles, exact numeric fields/fonts, layout/block/viewport ownership, paper setup and 25 scale-list entries/order.
- [ ] Verify all documented DXF entity/object variants and contexts against real files; SCALE currently has common group metadata only, and most record types remain opaque rather than editable.
- [ ] Verify mapped edits retain duplicate/unknown groups, subclass/application boundaries, dictionary entries, XDATA, reactors, extension dictionaries and per-vertex data through future DXF I/O.
- [ ] Compare OCS/arbitrary-axis coordinates, ARC degrees, ellipse parameters, bulged/width polylines and affine transforms with the reference; wire pure native geometry into persistent edit commands.
- [ ] Compare numerical NURBS/fit spline closest points, length, area and conservative bounds; verify natural omitted-tangent conditions/nonzero fit tolerance, matching periodic tangents and the unsupported arbitrary periodic tangent case.
- [ ] Compare live providers with installed AutoCAD: DATE/CDATE (HanCAD discards milliseconds), TDCREATE/TDUPDATE/TDINDWG/TDUSRTIMER after NEW/save/reopen, UCSNAME `""` in World, CLAYOUT `name*handle` after tab clicks and SETVAR, EXTMIN/EXTMAX (HanCAD reports live geometry bounds; empty = ±1E+20), VIEWCTR/VIEWSIZE/SCREENSIZE, LOCALE KOR/ENU and closed-palette state 0. Identity/path/codepage values (LOGINNAME, PLATFORM, SYSCODEPAGE, DWGCODEPAGE, ACADVER, PRODUCT, user paths) stay explicitly unavailable in browser mode and need a native provider.
- [ ] Verify the 28 audited documented ranges (e.g. CBARTRANSPARENCY 10-90, CLIPROMPTLINES 0-50, TEXTQLTY 0-100) reject out-of-range input with the same Korean message; SELECTIONEFFECTCOLOR accepts 0 (documented initial) plus 1-255. Confirm normalized angles (GFANG, LOFTANG1/2) and conditional limits (FACETERSMOOTHLEV, MAXACTVP) that HanCAD does not reject.
- [ ] Check whether switching layout tabs is recorded in the undo journal (HanCAD: tab clicks are not, SETVAR CLAYOUT is).
- [ ] Verify Korean direct-sysvar prompts, OSMODE 4133/invalid 99999, SETVAR LUPREC 2, read-only values and all shared-profile/per-document scopes against installed AutoCAD.
- [ ] Compare UNDO count/marks/groups/Control and live UNDOCTL. Wheel zoom, middle-button pan, double-middle and ZOOM E are recorded navigation steps merged by Combine; check U/REDO restore the identical view. Auto groups a whole `runMacro` menu macro; verify against a real multi-command menu item once Phase 03 macros exist.
- [ ] Layer category combination (UNDO Control Layer) awaits the Phase 08 Layer Properties Manager; the journal already merges consecutive `layer` changes.
- [ ] Compare implemented REDO's immediate-after-U/UNDO window and last undo batch against the installed reference; compare MREDO count/All/Last and OOPS after intervening edits and document reactivation.
- [ ] Verify NEW/OPEN/tab switching preserve independent graphs/history/blobs and shared profiles; provisional commands cancel without leaking into another document.
- [ ] Verify full .hcd and active recovery preserve opaque records/reference graphs/blobs; test delayed old-document cache writes and failures, and distinguish clean reload history from retained tab history.
- [ ] Verify D/DV/DRE use the supplied specification and do not use legacy aliases.
- [ ] Verify command prefixes, last-command repeat, cancellation and transparent commands.
- [ ] Verify Korean IME command entry and Korean free-text composition on Windows.
- [ ] Verify selection with PICKAUTO/PICKDRAG and lasso/window/crossing settings.
- [ ] Compare rectangular drag window/crossing and Shift removal; implement lasso, click-click and full PICKAUTO/PICKDRAG behavior.
- [ ] Verify selected-object drag/Ctrl-copy, snapped targets with Ortho, PICKADD/PICKFIRST and whole-command COPY undo.
- [ ] Complete COPYMODE, Array, Undo and Displacement beyond repeated two-point copies.
- [ ] Compare APERTURE/AUTOSNAP feedback, exact endpoints/intersections at large coordinates and dense zoom levels.
- [ ] Verify real mouse/trackpad wheel deltas, ZOOMFACTOR/ZOOMWHEEL, MBUTTONPAN and double-middle extents; complete MBUTTONPAN=0 shortcut menu.
- [ ] Verify DIST decimal values/angle settings; implement other unit formats, Multiple and transparent nesting.
- [ ] Verify direct-distance bases at dimension placement prompts and empty object-pick behavior.
- [ ] Verify block insertion and drawing opening use distinct drop targets.
- [ ] Verify one completed command corresponds to one undo group.
- [ ] Review transitional auto-fit after LAYON when all imported layers were off.
- [ ] Verify advanced LINE/CIRCLE/RECTANG/PLINE options beyond the initial usable subset.
- [ ] Verify complete opaque-object and reference preservation across I/O.
- [ ] Verify DIMSCALE changes annotation sizes without changing measurements.
- [ ] Verify DIMLINEAR H/V/Rotated and text-angle placement against the reference.
- [ ] Verify angular quadrant/reflex selection for two lines, arcs and three points.
- [ ] Verify smart DIM hover choices, placement and repeated-command behavior.
- [ ] Verify DIMZIN/DIMPOST/DIMLFAC and the supported basic style fields against ISO-25.
- [ ] Implement and verify DIMASSOC 2 geometry references; current dimensions are independent definitions.
- [ ] Complete the seven DIMSTYLE tabs, fit rules, leaders, tolerances and remaining Phase 11 commands.
- [ ] Verify large survey coordinates, floating origin, snapping latency and rendering budgets.
- [ ] Verify all phase acceptance criteria before changing phase status to complete.
- [ ] Compare TRIM/EXTEND Quick/Standard line picks, finite fences, Shift switching, local Undo, implied EDGEMODE boundaries and locked boundary selection.
- [ ] Complete TRIM/EXTEND non-LINE targets, hatch boundaries, Project, Crossing and Erase options before full Phase 07 acceptance.
- [ ] Compare OFFSET Through/Multiple/Erase/Layer defaults, session-only OFFSETDIST and exact miter results; implement GAPTYPE 1/2, curved/concave polylines and remaining curve types.
- [ ] Compare TEXT baseline, 1.25-height line advance, text cap-height/font metrics, rotation and readable in-place editing against the Windows reference.
- [ ] Verify actual Windows Korean IME candidate-window placement and Hanja; synthetic browser composition tests do not certify those native behaviors.
- [ ] Complete TEXT justification/styles/control codes, existing-text editing, SHX/BigFont and full MTEXT; verify original Phase 10 acceptance independently.
