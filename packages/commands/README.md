# @hancad/commands

## Responsibility

Canonical command registry, PGP aliases and asynchronous headless command execution.

## Allowed dependencies

@hancad/db, @hancad/sysvars, @hancad/editor, @hancad/input, @hancad/geom.

## Current status

The Phase 03 catalog (`src/catalog/`) registers 372 commands with canonical and
global names, Korean/English display names and help, ObjectARX-style flags
(transparent, modal, pickfirst, no-undo) and the phase that owns each complete
command. Application hooks register implementations; catalog metadata stays
authoritative. Built-in aliases combine Reference B with 172 extended acad.pgp
pairs; user acad.pgp files (aliases and external commands) merge over them and
REINIT reloads them, with AutoCorrect entries resolved last. `docs/COMMANDS.md` is
generated by `pnpm docs:commands`.

Typed command/input failures have locale-specific headless presentation. An
optional runner error formatter lets the app present errors from its registered
commands without adding UI or export-package dependencies here. Prefix parsing,
UNDEFINE/REDEFINE and the headless input runner are implemented. Unimplemented
canonical commands are explicitly reported as not implemented.
